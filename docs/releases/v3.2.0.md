# responsive classroom v3.2.0

## Windows portable package

Download `ResponsiveClassroom-Portable-windows-x64-v3.2.0.zip`, extract the entire archive, and run `ResponsiveClassroom.exe`. Keep `_internal` beside the EXE. macOS is no longer maintained.

## Changes

- The optional phone remote uses the same Wi-Fi network and shows only seven mode buttons. Its separate desktop page beside Timers shows the URL and has an activation checkbox. Only a connected, activated phone controls the four classroom scenarios; desktop speech can still select Question, Correct, and Wrong. The desktop remains responsible for microphone input, noise detection, playback, and lights.
- Four desktop scenario buttons keep square proportions and each contains separate small MP3 and voice switches. The phone page does not show those switches.
- Rest has a separate second-stage reminder audio selection. Selected mode MP3s repeat until the mode changes.
- `no sensor` / `關閉語音` pauses mode voice commands while noise detection continues. `sensor on` / `啟動語音` resumes voice commands.
- The window and interface title is `responsive classroom`.

## 使用說明

- 手機與電腦連上同一 Wi-Fi，在電腦「計時」旁的「手機控制」頁顯示網址，使用該網址開啟手機按鈕頁。手機頁只有待機、請注意、討論、休息、提問、答對、答錯七個按鈕。手機連線且勾選「啟動手機控制」後才接管四個情境。
- 電腦版四個情境按鈕保持正方形，每個按鈕內的小喇叭與麥克風分別控制該情境的 MP3 播放與語音切換。手機連線且啟動控制時，四個情境改由手機按鈕切換；提問、答對、答錯仍可由電腦語音或手機按鈕切換。
- 休息第二段可另選音檔。播放中的情境音檔會循環播放。說「關閉語音」或 `no sensor` 只暫停模式語音指令，噪音偵測繼續運作；說「啟動語音」或 `sensor on` 可恢復。

The included offline model and runtime are packaged in the ZIP. Microphone permissions and the physical microphone, speaker, network, and light panels still need checking on each destination computer.
