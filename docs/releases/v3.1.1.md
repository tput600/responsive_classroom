# Responsive Classroom v3.1.1

## Changes

- Keep speech detection live while Question, Correct, and Wrong cues play, so a new voice command can switch modes immediately. Detection remains paused during the Rest countdown.
- Classify noise from measured level rather than speech/environment labels. Faster response defaults use 8/15 dB Notice thresholds and 12/19 dB Discussion thresholds, 0.45/0.75 second entry holds, 1.2 second exit hold, and 300 ms smoothing. Custom settings are preserved during migration.
- Scale Notice and Discussion playback with the detected noise level, up to the configured playback volume.
- Retain voice-activity detection for speech segmentation; it no longer gates the noise-level meter.

## 變更內容

- 提問、答對、答錯音效播放時，語音偵測保持運作，可立即用新語音指令切換模式；REST 倒數仍會暫停偵測。
- 噪音級數依實測音量判斷，不再依賴人聲／環境音標記。注意模式預設門檻為 8／15 dB，討論模式為 12／19 dB；進入等待縮短為 0.45／0.75 秒，退出等待為 1.2 秒，平滑時間為 300 ms。升級時保留自訂設定。
- 注意與討論音效會隨偵測級數提高音量，最高到播放設定的音量。
- 語音活動偵測仍用於人聲斷句，不再控制噪音音量偵測。

## Validation and limits

The local Windows development run passed 320 unit tests; 42 platform- or fixture-dependent tests were skipped. Release publication still requires the exact-main Windows build, universal2 macOS build, native arm64 and x86_64 checks, and combined archive validation. Real microphones, speakers, classroom conditions, and physical WLED panels still require manual testing. The Mac app is not Developer ID signed or notarized. Redistribution rights for the supplied Blue Danube recording have not been independently verified.
