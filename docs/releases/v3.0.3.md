# Responsive Classroom v3.0.3

macOS compatibility and cross-platform development baseline. 原始碼已整合 Mac 適配，後續請以 main 最新內容繼續修改。

## Downloads / 下載

- Windows x64: extract the complete Windows ZIP and run ResponsiveClassroom.exe; keep `_internal` beside it.
- Apple Silicon: macos-arm64 ZIP, macOS 14+.
- Intel Mac: macos-x86_64 ZIP, macOS 14+.
- Mac: extract the complete archive and keep ResponsiveClassroom.app intact. Separate native builds, not universal2.
- Each ZIP includes offline models, runtime, notices, and a separate SHA-256 checksum. Python is not required for recipients.

## Changes

- Mac microphone consent is handled on the UI thread before capture starts, with clear pending/denied guidance.
- Application metadata includes microphone/local-network purpose declarations and version information.
- Sealed .app contents are preserved; manuals and manifests are outside the bundle.
- ZIP verification covers framework links, executable permissions, hashes, and relocated frozen model/Web UI checks.
- Native Windows, Apple Silicon, and Intel builds must pass before this release is published.

## Validation limits and signing / 驗收限制

CI verifies native packaging, automated unit tests, model integrity/inference, local Web UI, and audio decoding. Mac CI also verifies the extracted bundle's ad-hoc signature and executable architecture. CI does not validate actual microphone consent dialogs, physical CoreAudio devices, Finder launch, Bluetooth/USB transitions, sleep/wake, WLED hardware, or clean-user installation.

**Mac packages are ad-hoc signed, not Apple Developer ID signed or notarized. Gatekeeper may block downloaded packages. Do not disable Gatekeeper or Chromium's sandbox.** See MACOS.md for the manual acceptance checklist. Windows packages do not have a commercial code signature. Oldest advertised macOS 14 and clean Windows VM acceptance remain unverified.

Private SAPI replay fixtures are not distributed; their tests are explicitly skipped. Microphone audio is processed locally and not recorded/saved by this app.
