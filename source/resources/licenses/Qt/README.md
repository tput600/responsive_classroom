# Qt / PySide6 source documentation

Unmodified HTML copies of official licensing, SBOM, PySide6 licensing and FFmpeg attribution pages. Qt official docs identify Qt 6.11.2; these documents explain licensing and source provenance but do not prove a particular binary build configuration. The official general Qt 6.11 third-party attribution index and its linked component texts (146 pages) are saved in [`ThirdParty/`](ThirdParty/), while the separate Chromium/WebEngine notices are in [`../QtWebEngine/`](../QtWebEngine/).

The PySide6_Addons 6.11.2 RECORD hashes match the installed `avcodec-61.dll`, `avformat-61.dll`, and `avutil-59.dll`; their embedded metadata reports FFmpeg 7.1.5, `LGPL version 2.1 or later`, `--enable-shared`, and `--disable-static`, with no `--enable-gpl`, `--enable-version3`, or `--enable-nonfree` options. Use the complete FFmpeg 7.1.5 attribution below for these binaries. The older Qt 6.11.2 documentation snapshot identifies FFmpeg 7.1.3 and remains here only to document the source of the earlier discrepancy; it is not the applicable notice for the RECORD-verified DLLs. Complete embedded configure metadata and SHA-256 values are in [`REDISTRIBUTION.md`](REDISTRIBUTION.md).
